# Globe painting sources

Each image is copied from `sketchnomad-backend/supabase/storage/sketches/` and each place, title and coordinate comes from the matching record in `sketchnomad-backend/seed/uat/<artist>.sql`: the same historical works the app shows on its map.

- `van-gogh-auvers.jpg`: Green Wheat Fields, Auvers, Vincent van Gogh. Record in `seed/uat/vincent_vangogh.sql`, file `historical/vincent_vangogh/Green_Wheat_Fields_Auvers.jpg`.
- `levitan-vladimirka.jpg`: The Vladimirka Road, Isaac Levitan. Record in `seed/uat/isaac_levitan.sql`, file `historical/isaac_levitan/Vladimirka_Levitan.jpg`.
- `yoshida-taj-mahal.jpg`: Morning Mist at Taj Mahal, Hiroshi Yoshida. Record in `seed/uat/hiroshi_yoshida.sql`, file `historical/hiroshi_yoshida/hiroshi_yoshida_morning_mist_in_taj_mahal.jpg`.
- `north-matang.jpg`: View of Matang, Sarawak, Borneo, Marianne North. Record in `seed/uat/marianne_north.sql`, file `historical/marianne_north/Marianne_North_1830-1890_-_View_of_Matang_Sarawak_Borneo_-_MN542_-_Marianne_North_Gallery_Royal_Botanic_Gardens_Kew.jpg`.
- `kuroda-lakeside.jpg`: Lakeside, Kuroda Seiki. Record in `seed/uat/kuroda_seiki.sql`, file `historical/kuroda_seiki/Kuroda-seiki-kohan00-6-1b.jpg`.
- `bierstadt-sierra-nevada.jpg`: Among the Sierra Nevada, California, Albert Bierstadt. Record in `seed/uat/albert_bierstadt.sql`, file `historical/albert_bierstadt/Albert_Bierstadt_-_Among_the_Sierra_Nevada_California_-_Google_Art_Project.jpg`.
- `cole-oxbow.jpg`: View from Mount Holyoke (The Oxbow), Thomas Cole. Record in `seed/uat/thomas_cole.sql`, file `historical/thomas_cole/Cole_Thomas_The_Oxbow_The_Connecticut_River_near_Northampton_1836.jpg`.
- `carr-gravel-pit.jpg`: Above the Gravel Pit, Emily Carr. Record in `seed/uat/emily_carr.sql`, file `historical/emily_carr/Above_the_Gravel_Pit_by_Emily_Carr_1937_oil_on_canvas.jpg`.
- `church-chimborazo.jpg`: Chimborazo Volcano, Frederic Edwin Church. Record in `seed/uat/frederic_church.sql`, file `historical/frederic_church/Chimborazo_Volcano.jpg`.
- `north-gongo.jpg`: Butterflies' Road through Gongo Forest, Brazil, Marianne North. Record in `seed/uat/marianne_north.sql`, file `historical/marianne_north/Marianne_North_1830-1890_-_Butterflies_Road_through_Gongo_Forest_Brazil_-_MN82_-_Marianne_North_Gallery.jpg`.
